# AI Lead Follow-Up Automation 🤖

A Python portfolio project by Rinna demonstrating how to generate personalized follow-up email drafts from a CSV file.

## 🎯 Problem

Businesses can lose track of enquiries when follow-up is handled manually.

## 💡 Solution

This project reads fictional lead data, validates required fields, generates personalized email drafts, and saves them for human review.

## ✨ Features

- Reads lead information from a CSV file.
- Checks required fields.
- Generates personalized follow-up drafts.
- Saves drafts to a CSV output file.
- Skips invalid records.
- Does not send emails automatically.

## 🛠️ Technologies

- Python
- CSV data processing
- Workflow automation
- GitHub

## 🚀 How to Run

You need Python 3.9 or later.

```bash
python src/generate_followups.py
```

The generated drafts will be saved to:

`output/follow_up_drafts.csv`

## 🔒 Safety

This project uses fictional sample data. No emails are sent. Never upload private customer information, passwords, or API keys.
